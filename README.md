# Voice Recognition System

A Python-based voice recognition system that recognizes predefined
voice commands such as ON, OFF, START and STOP.

## Features

- Voice command recognition
- Recording voice templates
- Predefined command detection
- Simple Python implementation

## Technologies Used

- Python
- Speech Recognition
- PyAudio

## Project Files

- main.py – Main voice recognition program
- record_templates.py – Records voice templates
- requirements.txt – Required Python libraries

## Installation
Install the required libraries:
Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to run
first record the voice templates
```bash
python record_templates.py
```
then run the recognition system
```bash
python main.py
```
